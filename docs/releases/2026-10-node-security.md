# October 2026 Node.js security update

Release: 0.2.3

Require patched Node.js runtimes: 22.23.4, 24.22.1 or 26.12.1 in the supported release lines. Runtime pins, CI and container builds follow those minimums where applicable. This addresses the October 21 Node.js security release, including CVE-2026-111497, CVE-2026-105482 and the accompanying TLS, HTTP, crypto and permission fixes. Existing application dependencies and persistent data are preserved.
